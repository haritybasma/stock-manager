# Stock Manager

Application de gestion de stock avec CRUD complet, développée pour renforcer mes bases
en PHP/MySQL.

## Fonctionnalités

- Ajouter, lister, modifier et supprimer des produits
- Requêtes préparées (protection contre les injections SQL)
- Formulaires avec validation

## Stack technique

- **Back-end** : PHP, MySQLi
- **Front-end** : HTML, CSS
